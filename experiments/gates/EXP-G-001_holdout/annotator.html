What am I judging? (read once)

You read an explanation written about a network-traffic classification. For every feature listed, say what the text itself claims about that feature's effect on the predicted class's score:

  • + raises — the text says this feature pushes the score up / toward the predicted class.
  • − lowers — the text says it pushes the score down / away.
  • unclear — the text mentions the feature but does not commit to a direction.
  • absent — the text does not actually talk about this feature. Some listed features are there precisely because they are not in the text.

If the text claims a feature that is not in the list, add it using the box at the bottom of the panel. Missing claims matter as much as wrong ones.

Judge only what the prose says. Do not judge whether the text is correct about the traffic — that is a different question and not this task. Tick hedged when the text states a direction but softens it ("may slightly reduce", "possibly lowers").
